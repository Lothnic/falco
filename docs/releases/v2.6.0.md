# Falco 2.6.0 — Command Mode

Falco can now change the text you have selected, or write something new, from a
spoken instruction. Command Mode is opt-in, runs on the same local AI as voice
editing, and never sends your text anywhere.

## Command Mode

- **Turn it on once.** Open **Settings → General → Command
  Mode**, then pick a shortcut. The default is **Ctrl+Alt+C**. Leave the shortcut
  empty to disable it, or untick Command Mode to turn the feature off. The GTK
  Preferences window has the same controls.
- **Rewrite a selection.** Select text in any app, press the shortcut, say the
  change, and press it again. For example: **make this shorter**, **turn this
  into an email**, **make this a bulleted list**, or **fix the grammar**. Exact
  edits and the app's own formatting shortcuts work as they do in voice editing.
- **Write from nothing.** With no selection, say what to write: **a short note
  saying the deploy moved to Friday**, **write a reply saying I will be late**,
  or **two sentences about why walking helps me think**. Falco tries a voice
  command first; if none matches, the local AI drafts the text and types it at
  the cursor.
- **Voice commands still work.** **open Firefox**, **search the web for train
  times**, **select the next sentence**, and the other existing commands run in
  Command Mode too. They continue to respect the Falco Labs settings.
- **See what is happening.** Rune's recording overlay says **Command** while it
  listens and **Finishing…** while the AI writes. Esc stops a command recording.
  Command Mode does not automatically submit drafts.

## Local and safe by default

Command Mode uses the same on-device refiner engine as voice editing. Enabling Command Mode in Rune downloads missing AI files before saving
(about 1 GB, shared with self-corrections and voice editing). Choose the model
in **Settings → Refiner**. Nothing is uploaded, and no account or
network connection is needed after the models are installed.

Before typing, Falco checks that the focused window and selection have not changed, refuses
password fields and terminals, and puts your clipboard back after reading a
selection. Like voice editing, Command Mode currently needs a Wayland session.
On X11 it reports that instead of guessing.

## Upgrading

Command Mode is off by default, so existing dictation, voice editing and voice
commands behave as before until you enable it. Settings, custom words, snippets,
usage history and downloaded models are kept.

```sh
curl -fsSL https://falco.lothnic.dev/install.sh | bash
```

Quit Falco and close existing dashboard or Preferences windows before reopening
after the upgrade. Package-managed copies update through their package manager.

## Notes

- Drafting quality depends on the local model and the instruction. Review a draft
  before sending it; a short instruction can be read more than one way.
- Command Mode is separate from voice editing: the existing **Shift + dictation
  key** shortcut keeps working unchanged.
- The new settings are available in both Rune and the GTK compatibility
  preferences. The Rune catalog and its settings fixture stay in sync.

## Repairing a 0.1.0 installation

The installer identifies the original 0.1.0 package using both its package
metadata and Python version marker. For that version only, it stops the old
app processes, removes the old app and its owned launchers from their active
paths, then performs a fresh installation. Old launch-at-login entries are
repointed to the stable Falco launcher after success.

Settings, vocabulary, snippets and downloaded models are retained. Newer
releases, unknown installations and unrelated shortcuts are not removed. The
old app is held in a private recovery location during installation and is
restored if the new installation fails; recovery copies are deleted after
success. Interrupted migrations are recovered when the installer is retried.

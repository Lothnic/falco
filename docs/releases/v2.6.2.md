# Falco 2.6.2 — Spoken corrections

Change your mind while dictating and keep the corrected wording in the final text:

- **“Meet on Monday, no, Tuesday.”** → **“Meet on Tuesday.”**
- **“Use red paint, not that, blue paint.”** → **“Use blue paint.”**
- **“Order two boxes of screws, no wait, three boxes.”** → **“Order three boxes of screws.”**

Enable **Settings → Refiner → Refine dictation** and finish any missing model
download. Say the replacement before releasing the dictation key. No new model
is required if the refiner is installed, and DFlash is optional.

## What changed

The Phonon prompt explicitly tells the refiner to remove abandoned wording and
correction phrases, retain the replacement, and preserve unrelated details,
ordinary negations, quoted or reported speech, and the transcript's language and
script. The smaller Gemma/Llama fallback prompt has matching cue guidance.

Clear **“no”** and **“not that”** cues are recognized across sentence boundaries
and pauses, alongside **“no wait”**, **“I mean”**, **“make that”**, **“scratch that”**
and **“or rather”**. Ordinary statements such as **“no problem”** and **“not that
important”** should retain their meaning. An ambiguous bare “no” is less reliable
than “no wait” followed by the replacement.

A valid correction can remove enough words to fail the normal length guard.
For transcripts up to 64 words, a shorter answer is now accepted when the
existing structural correction check can account for the deletion. The same
check applies to a refinement prefetched while recording. Longer transcripts
retain the normal guard, so a collapsed answer does not trigger an expensive
search over possible edits or silently replace a long dictation.

With **Type at pause**, a preceding phrase may already be visible. Falco checks
the correction and typing destination before replacing that phrase in the same
recording. If the edit cannot be verified or typing is no longer safe, it keeps
the earlier text and types the new phrase as spoken. This is not an instruction
to delete arbitrary text from earlier recordings or another app.

## Validation and scope

- **297 Python tests**, including 26 regression cases for cues, literal negations,
  split sentences, invalid replacements, short-result checks, prefetch and
  Type at pause replacement behavior.
- **15 synthetic transcripts checked with the pinned Phonon Q4_K_S target**,
  covering corrections, literal negations, reported speech, questions and
  instruction-like text. These are functional checks, not an accuracy benchmark.
- Existing Rune interaction tests, website checks, and Ubuntu packaging checks
  run for this release. The model check did not exercise microphone recognition
  or compositor-level text insertion.

The historical **2.5 DFlash benchmark** remains available with its original data
and method. This release changes the cleanup prompt; those timings have not
been rerun with the new prompt. No new latency or accuracy gain is claimed.

## Upgrade

```sh
curl -fsSL https://falco.lothnic.dev/install.sh | bash
```

Quit Falco and close existing windows before reopening after the upgrade.
Settings, vocabulary and downloaded models are retained. The optional drafter
prompt, model-download repair, Command Mode and verified 0.1.0-only installer
repair remain included. Package-managed copies update through their package manager.

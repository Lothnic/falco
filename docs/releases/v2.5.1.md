# Falco 2.5.1 — Unified interface

Falco’s everyday controls now live in one Rune window, keeping the dark
slate-and-mint appearance across settings, vocabulary, usage and backups.

## Changes

- **Complete settings pages.** Search settings across General, Speech, Audio,
  Refiner, Text, Appearance and Advanced. Apply or discard changes together.
  Invalid values stay editable; failed or cancelled downloads preserve the
  saved setup and unsaved edits. Downloads run outside the UI with progress.
- **Words and snippets.** Add, edit, search and remove custom words, alternate
  pronunciations and snippet expansions without opening GTK Preferences.
  Existing vocabulary validation protects phrases already assigned elsewhere.
- **Usage, updates and backups.** View counts, speaking duration and estimated
  time saved; check or install updates; save backups and restore earlier copies.
  Destructive actions ask for confirmation inside the same window. Desktop file
  pickers and system authentication continue to use the operating system.
- **One window.** Tray settings, words, usage, help and about actions reuse the
  running dashboard. Unsaved edits survive navigation and closing/reopening the
  window. Dropdowns appear above scrolling content; keyboard controls and a
  minimum window size keep the layout usable.
- **Matching UI delivery.** The Linux x86_64 installer downloads the exact
  release’s Rune bundle and verifies its SHA256. Older cached dashboards are
  never reused. Prebuilt binaries target Ubuntu 24.04 / glibc 2.39 or newer;
  source builds require Rust 1.99.1+. GTK remains the compatibility fallback
  where Rune is unavailable. First-run setup retains its existing screens.

## Refinement and benchmarks

The 2.5 refiner engine, optional 215 MB DFlash2 drafter and streamed previews
are retained. Enable acceleration in **Settings → Refiner**. Enable **Show live
transcript** in **Settings → Appearance**, and **Start typing sooner** in
**Settings → Audio** for CPU Parakeet previews during pauses.

The published Linux results remain the **2.5 engine measurements**, not a new
2.5.1 end-to-end benchmark: 32% less total refiner-request time (1.47× faster)
against the 2.4.2 decoding baseline on an RTX 4060 Laptop GPU. The 60-token
output took 198 ms versus 371 ms. Very long outputs and CPU-only performance
have not been measured. [Method and raw data](../benchmarks/README.md).

## Install or upgrade

```sh
curl -fsSL https://falco.lothnic.dev/install.sh | bash
```

Quit Falco and close existing dashboard/Preferences windows, then reopen it
after upgrading. Existing settings, words, snippets and model downloads remain.
The drafter is still optional and is not downloaded merely by upgrading.

For a local Rune build, use the installer’s `--with-rune` option with Rust
1.99.1+. Package-managed copies are updated through their package manager.

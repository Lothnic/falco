# Falco 2.5.0 — Refiner edition

Falco 2.5 adds optional DFlash2 acceleration to the Phonon refiner and streams
provisional cleanup into the Rune overlay. Longer generated output benefits
most in the initial Linux test.

## Changes

- **Optional Phonon acceleration.** Enable **Preferences → Advanced → Accelerate
  Phonon refinement (experimental)** for a one-time 215 MB drafter download. The
  refiner and matching drafter stay pinned and SHA256-checked. A startup, warm-up
  or engine failure retries with ordinary decoding. Other refiner models keep
  their usual decoding.
- **Streamed cleanup previews.** Enable **Preferences → Audio → Customize → Show
  a live transcript in Rune** to see provisional cleanup while finishing. With
  **Start typing sooner** and CPU Parakeet, previews also stream during speech
  pauses. Only complete, checked text is inserted into the focused app.
- **Reuse work already running.** Releasing the key can reuse an exact-transcript
  refinement still in flight. Cached results must also match the writing mode,
  engine and vocabulary. Match-the-app mode resolves before prefetching.
- **Recovery and cancellation.** Interrupted streams clear the preview and retry
  through the complete-response path; truncated output is rejected. Late previews
  cannot overwrite a newer recording, and an unavailable overlay does not discard
  a valid refinement.
- **Version alignment.** App, Rune dashboard, website and release metadata identify
  this release as 2.5.0.

## Initial Linux benchmark

On Linux/Vulkan with an **RTX 4060 Laptop GPU (8 GB)**, the accelerated
configuration used **32% less total refiner-request time (1.47× faster)** across
four synthetic prompts, measured twice after warm-up. The 60-token output took
**198 ms versus 371 ms** for the v2.4.2 decoding baseline, **1.87× faster**.
The shortest output was approximately unchanged. Outputs matched throughout.

Streamed text first arrived in approximately **47–51 ms**, before overlay rendering.
This test measures refinement requests only. It excludes speech recognition,
cold loading, UI rendering and final text insertion; CPU-only and very long
outputs have not been measured. Speed varies by hardware and workload.

## Install or upgrade

```sh
curl -fsSL https://falco.lothnic.dev/install.sh | bash
```

For the Rune dashboard and streaming overlay:

```sh
curl -fsSL https://falco.lothnic.dev/install.sh | bash -s -- --with-rune
```

Acceleration and live previews are optional and off by default. Existing settings
and downloaded models are retained. Updating does not automatically download the
drafter. Turn acceleration off if ordinary decoding is faster on your machine.
